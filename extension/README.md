# PC 브라우저에서 직접 수집하기

이 확장 프로그램은 평소 사용하던 PC의 Chrome·Edge에 로그인된 Instagram 화면을 읽습니다. 서버에서 Instagram에 로그인하지 않으므로 클라우드 로그인 경로를 쓰지 않습니다. PC에서도 Instagram이 보안 확인을 요청하면 브라우저에서 정상적으로 확인해야 합니다.

## 설치

1. Wherewego 앱의 **PC에서 가져오기 → 확장 프로그램 받기**로 ZIP을 받아 압축을 풉니다.
2. Chrome은 주소창에서 `chrome://extensions`, Edge는 `edge://extensions`를 엽니다.
3. **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. `manifest.json`이 있는 폴더를 선택합니다. 주소창 옆 확장 프로그램 메뉴에서 Wherewego를 고정하면 편리합니다.

GitHub에서 설치할 때는 저장소를 내려받아 `extension/` 폴더를 선택해도 됩니다. 이 설치 ZIP은 프로그램 파일이며 Instagram 자료 내보내기 파일이 아닙니다. Chrome 웹스토어 배포본은 아닙니다.

## 사용

1. 평소 사용하는 PC 브라우저로 https://www.instagram.com/ 에 로그인합니다.
2. 저장함, 특정 DM 대화 또는 게시물 상세 화면을 엽니다. 홈 피드·일반 프로필·DM 목록은 수집하지 않습니다.
3. 확장 프로그램에서 **현재 화면 수집** 또는 **스크롤하며 수집**을 누릅니다. 스크롤 수집은 최대 20번, 총 500개까지입니다. 수집 중 이 창을 열어두세요. 창을 닫으면 수집이 중단되고 목록이 지워집니다.
4. 제목·링크·출처를 확인하고 불필요한 항목은 삭제합니다. **목록을 앱으로 보내기**를 누릅니다.
5. https://ml-cherry-wherewego.web.app 에서 관리자 로그인 후 목록을 확인하고 **가져오기**를 누릅니다. AI 사용은 앱에서 선택합니다.

전송 주소가 너무 길면 항목을 나누어 보내거나 **JSON 복사** 후 앱의 붙여넣기를 사용하세요. 기본 앱 주소와 현재 배포된 Wherewego Cloud Run 주소만 허용합니다. 직접 운영하는 다른 주소를 쓸 경우 `popup.js`의 `TARGETS`를 확인하고 수정해야 합니다.

저장함의 격자는 캡션을 제공하지 않는 경우가 많습니다. URL만 있는 항목은 상세 게시물을 연 뒤 다시 수집하면 설명을 보완할 수 있습니다. 이미지·영상만 있고 설명이 없다면 AI가 정확히 분류할 수 없어 분류 보류로 남을 수 있습니다. 전체 저장함이나 모든 대화를 자동으로 가져오는 기능은 아닙니다. Instagram의 화면 구조에 따라 DM 메시지 영역을 찾지 못할 수 있으며, 이때 다른 영역을 읽지 않고 중단합니다.

## 데이터와 권한

- 사용자 클릭으로 현재 Instagram 탭의 화면 DOM만 읽습니다. Instagram 비밀번호·로그인 쿠키·토큰을 읽거나 전송하지 않습니다.
- 권한은 `activeTab`, `scripting`, 앱 주소 저장용 `storage`, 명시적인 JSON 복사용 `clipboardWrite`입니다. 상시 사이트 접근 권한·백그라운드 작업·원격 요청은 없습니다.
- 수집 목록은 확장 팝업 메모리에만 보관됩니다. 앱 주소만 브라우저에 저장합니다.
- 앱으로 보내기를 누르면 사용자가 확인한 링크와 설명을 URL의 `#wherewego=` 조각으로 전달합니다. URL 조각은 HTTP 요청으로 서버에 전송되지 않지만 브라우저 기록에는 남을 수 있습니다. 앱은 조각을 읽은 뒤 주소에서 제거합니다. 이후 가져오기 확인을 눌러야 서버에 저장됩니다.
- DM 외부 링크와 주변 메시지 설명에는 개인 정보가 포함될 수 있습니다. 전송 목록을 확인하고 공유하지 않을 항목은 삭제하세요. JSON 복사 내용도 개인 자료이므로 다른 곳에 붙여넣지 마세요.
