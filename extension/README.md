# PC 브라우저에서 직접 수집하기

확장 프로그램 0.2.0은 평소 사용하던 Chrome·Edge에 로그인된 Instagram에서 저장함, 열린 DM 대화, 게시물의 링크·설명·사진을 가져옵니다. PC에서 Instagram이 보안 확인을 요청하면 브라우저에서 직접 확인을 마친 뒤 사용하세요.

## 설치·업데이트

1. 앱의 **PC에서 가져오기 → 확장 프로그램 받기**로 ZIP을 받아 압축을 풉니다.
2. Chrome은 `chrome://extensions`, Edge는 `edge://extensions`에서 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램 로드**를 누르고 `manifest.json`이 있는 폴더를 선택합니다.
4. 기존 설치를 업데이트할 때는 새 파일로 기존 폴더를 덮어쓴 뒤 확장 프로그램 카드의 **새로고침**을 누릅니다. 버전이 **0.2.0**인지 확인하고 **Instagram 탭도 새로고침**하세요. 기존 폴더를 바꾸기 어렵다면 기존 확장을 삭제하고 새 폴더를 로드해도 됩니다.

GitHub에서 설치할 때는 저장소의 `extension/` 폴더를 선택합니다. 설치 ZIP은 프로그램 파일이며 Instagram 자료 내보내기 파일이 아닙니다. Chrome 웹스토어 배포본은 아닙니다.

## 저장함·DM 가져오기

1. PC에서 https://www.instagram.com/ 에 로그인하고 저장함 또는 특정 DM 대화를 엽니다.
2. **현재 화면 수집**은 이미 불러온 내용을, **스크롤하며 수집**은 최대 20번 스크롤한 내용을 읽습니다. DM은 이전 메시지 방향으로 이동하며 다른 대화는 열지 않습니다. 링크는 최대 500개까지 가져옵니다.
3. DM 공유 카드가 URL 없이 표시되어 0개로 나오면 **DM 공유 게시물 찾기**를 누릅니다. 열린 대화 안의 공유 카드 최대 20개를 정상적으로 열어 실제로 표시된 게시물 주소를 확인합니다. 돌아오기 어려운 화면에서는 중단하고 직접 화면을 복원하라는 안내를 표시합니다. 숨겨진 게시물 ID로 주소를 추측하지 않습니다.
4. 제목·링크·출처를 확인하고 불필요한 항목을 삭제합니다. **목록을 앱으로 보내기**를 누릅니다.
5. 앱에서 관리자 로그인 후 목록을 확인하고 **가져오기·분류**를 누릅니다.

일반 프로필, 홈 피드와 DM 목록은 수집하지 않습니다. Instagram 화면 구조에 따라 일부 공유 카드를 열지 못할 수 있습니다. 전체 저장함이나 모든 DM 대화를 자동으로 가져오는 기능은 아닙니다.

## 사진·슬라이드·릴스 읽기

1. 저장함이나 DM에서 **게시물 상세 화면**을 먼저 엽니다. 주소가 `/p/…`, `/reel/…` 또는 `/tv/…`인 게시물에서 사용하세요.
2. 확장을 열고 **사진·슬라이드·릴스 읽기**를 누릅니다. 수집이 끝날 때까지 팝업을 열어두고 스크롤·탭 이동을 멈춰주세요. 팝업을 닫으면 수집을 중단합니다.
3. 현재 사진에서 시작해 다음 슬라이드를 최대 10장 읽습니다. 영상은 0%, 33%, 66%, 90% 지점의 대표 프레임을 최대 4장 읽으며 사진과 프레임을 합해 한 번에 최대 10장까지입니다. 사진·영상이 섞인 슬라이드도 지원합니다. 구간 이동이 불가능한 영상은 현재 프레임만 읽습니다.
4. 끝나면 슬라이드의 시작 위치와 영상의 재생 상태·시간·음소거 상태를 복원합니다. 화면을 복원하지 못한 경우 안내를 확인하고 직접 사진 위치를 확인해주세요.
5. **전송 전 확인**에서 실제로 보낼 사진을 확인합니다. 잘못된 게시물은 삭제하고 **목록을 앱으로 보내기**를 누릅니다. 같은 게시물을 저장함이나 DM에서 먼저 수집했다면 출처를 유지하면서 사진을 보완합니다.
6. 앱에서 AI 사용을 선택하고 가져오면 사진과 프레임에 보이는 글·주소·메뉴를 읽어 정리합니다. 음성이나 전체 영상 내용은 분석하지 않습니다. 작거나 흐린 글, 화면 밖 내용, 아직 불러오지 않은 사진은 읽지 못할 수 있습니다.

사진이 많아 전송 주소가 길면 **JSON 복사 → 앱의 PC에서 가져오기 → 붙여넣기**를 사용합니다. 붙여넣기는 최대 6MiB이며 넘으면 항목을 나누어 가져오세요. 이 팝업을 닫으면 수집 목록이 지워지므로 보내거나 복사하기 전에는 닫지 마세요. URL만 있는 저장함 격자는 상세 화면에서 사진·설명을 보완할 수 있습니다.

## 데이터와 권한

- 권한은 `activeTab`, `scripting`, 앱 주소 저장용 `storage`, 사용자가 누르는 JSON 복사용 `clipboardWrite`입니다. 상시 사이트 접근 권한이나 백그라운드 작업은 없습니다. Instagram 비밀번호·로그인 쿠키·토큰을 읽거나 보내지 않습니다.
- 사진 버튼을 눌렀을 때만 현재 탭의 스크린샷을 임시로 만들고, **현재 게시물의 실제 사진·영상 영역만 잘라** 팝업 목록에 보관합니다. DM 대화 전체, 로그인 화면, 댓글·사이드바를 스크린샷으로 보내지 않습니다. 탭·게시물·사진 영역이 바뀌면 해당 캡처를 버리고 중단합니다.
- 잘라낸 JPEG는 긴 변 최대 1280px·사진당 최대 75KiB, 게시물당 합계 최대 750KiB입니다. 대표 썸네일은 최대 320px·24KiB입니다. Instagram 이미지 CDN이나 원본 영상 파일을 직접 내려받지 않습니다.
- 목록은 팝업 메모리에만 보관하고 앱 주소만 브라우저에 저장합니다. 앱으로 보내기를 눌러야 사진·링크·설명이 전달됩니다. 사진이 포함된 JSON 복사 내용도 개인 자료입니다.
- 앱으로 보내기는 `#wherewego=` URL 조각을 사용합니다. URL 조각은 HTTP 요청으로 서버에 전달되지 않지만 브라우저 기록에는 남을 수 있습니다. 앱은 읽은 뒤 주소에서 제거합니다. 이후 앱에서 가져오기를 눌러야 서버에 저장하며 AI를 켜면 선택한 AI 제공자에게 사진과 설명을 보냅니다.
- DM 외부 링크와 게시물 설명에는 개인 정보가 포함될 수 있습니다. 전송 목록을 확인하고 공유하지 않을 항목은 삭제하세요. Gemini·관리자 비밀번호를 확장에 입력하지 않습니다.
- 기본 앱 주소와 현재 배포된 Wherewego Cloud Run 주소만 전송 대상으로 허용합니다. 직접 운영하는 다른 주소를 쓸 경우 `popup.js`의 `TARGETS`를 수정해야 합니다.
